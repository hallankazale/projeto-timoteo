# Projeto Timóteo

Site da Revista do Aluno do Projeto Timóteo.

## Conteúdo atual

- Estrutura do Volume 1
- Lição 4 – A Igreja e a Comunhão Cristã
- Parte 1 em duas páginas
- Layout adaptado para celular
- Botão para imprimir ou salvar em PDF

## Identidade visual

- Caixa de dados do aluno em azul-claro
- Texto-Áureo em amarelo
- Objetivos da Lição sem caixa colorida
- Cabeçalho da Leitura Bíblica em azul-escuro
- Caixa “Você Sabia?” em verde

## Publicar no GitHub Pages

No repositório, abra **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch **main** e a pasta **/(root)**. Depois clique em **Save**.
